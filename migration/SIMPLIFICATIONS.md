# 简化替代清单

> 本文件由 `python migration/gen_simplifications.py` 从 `matrix.tsv` 生成，**不要手工编辑**。

`简化替代` 的含义：**功能已经实现、能正常玩**，但与旧版的行为不完全一致，且这个不一致是被接受的取舍（不是漏做，也不是 bug）。当前共 **47 行**。

判据：如果某行的差异其实是「旧版没有这个功能」，它应该标 `增强`；
如果是「旧版有这个功能、新版完全没有入口」，标 `缺失`；只有「做了、但做法不同」才落在这里。

## 2. 差异模式（人工归纳）

这 47 行不是 47 个孤立差异，绝大多数能归到下面几类；同类之间改法一致，改一处就能一起推进。

| 模式 | 涉及行 | 说明 |
|---|---|---|

| C. 多入口合并成一个列表 | CHR-001 / CHR-004 / CHR-015 / ITM-001~003 / ITM-005~007 / SHO-016 / SHO-028 | 旧版按用途拆成多条命令（简略/详细/分类/按类型/单品详情/搜索2…），新版统一 `/背包`、`/我的角色`、`/市场` 一条入口 + 分页 + `@编号` 引用。信息没丢，但「一条命令直达某个视图」的捷径没有了。 |

| F. 报价系统从「双向物物交换」简化为「单向出售」 | SHO-015 / SHO-018 / SHO-019 | 旧版报价单是两边各自挂物品、双方确认后互换的状态机；新版是卖家挂一件、买家付钱成交。「双方都要放东西」这条路径不存在，因此也不存在接收方二次确认。 |
| G. 房间的「准备」位 | PLY-021 / PLY-023 | 旧版房间有 ready 状态，全员准备才开局；新版由房主直接开局（赛马房任何人可开），没有准备位。 |

## 4. 怎么用这份清单

- 想「补一个旧版入口」时，先在这里查它是不是已被有意简化：如果是，补之前要先决定「改成旧版的形态」还是「接受简化」。
- 想「改行为」时，改完记得同步 `matrix.tsv` 的 `diff` 列并重跑 `gen_matrix.py` / 本脚本，否则两处会打架。
- 清单里没有的行，要么是 `等价`（有夹具或测试守着），要么是 `增强`（旧版没做）。
